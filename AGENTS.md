# Project Rules

## General

- Follow the existing code style and patterns.
- Use yarn for running project commands.
- Keep code in TypeScript unless migration is required.

## Project

- 这是一个基于 Nuxt 4 的项目，使用 Vuetify 作为 UI 库。

## Stack

- Framework: Nuxt 4
- UI Library: Vuetify
- Enabled Features: Vuetify MCP, Pinia, Vue I18n, Tailwind CSS

# Guidelines

* Use TypeScript with strict type checking.
* Never commit secrets or `.env` files.
* Do not introduce `any` unless absolutely necessary.
* Avoid unnecessary dependencies and abstractions.
* Prefer small, simple, and composable modules.
